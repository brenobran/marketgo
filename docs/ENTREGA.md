# Checklist de entrega MarketGo

- [ ] Configurar Node.js 22+, VS Code, Expo Go, Supabase e Git.
- [ ] Criar projeto Supabase e executar `schema.sql` e `seed.sql`.
- [ ] Preencher `.env` local (não enviar ao Git).
- [ ] Testar cadastro/login e persistência de sessão.
- [ ] Testar busca, categorias, lojas fechadas e catálogo.
- [ ] Testar regra de uma loja por carrinho e pedido mínimo.
- [ ] Testar checkout, cálculo de total no servidor, histórico e cancelamento.
- [ ] Executar `npm run typecheck`, `npm test` e `npm run format`.
- [ ] Adicionar capturas de tela ao README.
- [ ] Publicar no GitHub sem `.env` nem credenciais privadas.
